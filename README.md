# BTL Event Gamification

MVP de plateforme de gamification pour conférences et événements BTL.

## Modules
- Quiz chronométré
- Tombola avec animation de tirage
- Questions / réponses avec intervenants
- Espaces Participant, Organisateur, Modérateur et Intervenant

## MVP
Cette première version fonctionne avec des données fictives en local. La couche data est volontairement isolée pour faciliter le branchement futur à Supabase.

## Démo
Application statique compatible GitHub Pages.

## Prochaine étape
Connexion Supabase : authentification, sessions d'événement, participants, questions, intervenants, quiz, réponses, tirages et historique.
